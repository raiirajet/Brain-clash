# Changelog
## 0.1.0 – development candidate
- Modular question generators, battle state, Flame arena and adaptive statistics.
- Four game modes, six learning worlds, local profile management, collections, settings and results.
- Android bootstrap and CI test APK workflow. No release signature.

- Original vector avatars and animated energy pulse, Android launcher icon, spaced practice queue and round records.

- Original synthesized sound effects, optional music, volume controls and native Android audio adapter.

- Age-based starting difficulty, optional number pad and broader memory/focus/word tasks.

## 0.2.0 – test candidate
- Interactive memory boards, focus signal, unlockable arenas and effects, new icon and splash, optimized test APK.

- German/English UI, extended stats, Android emulator smoke test and expanded multiplication practice.

## 0.3.0 — Arcade visual update
- Shared arcade theme, gradient mode/world tiles, XP progress, improved navigation surfaces, score HUD, answer feedback and combo display, coloured energy territories, directional attack particles, memory tile styling, and animated accuracy results. Existing game logic and storage retained.

- Separate visual arenas for practice and cooperative modes, settings icons, and independent player pulse test.
