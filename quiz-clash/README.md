# Quiz Clash 0.1.4 – Testversion
Eigenständige native Android-App im selben Repository, ohne Änderungen an Brain Clash. Package ch.quizclash.mobile. Keine Internetberechtigung oder Registrierung. Deutschschweizer Schulquiz, 1–9, kein Rechnen.

## Fragen
5'400 feste Multiple-Choice-Lernfragen in neun JSON-Assets unter app/src/main/assets/bank/, exakt 600 pro Klasse. Enthält die bisherigen 27 Demo-Fragen, 691 neu entworfene Wissensfragen und 4'682 regelbasierte Sprach- und Anwendungsübungen. Keine Rechenaufgaben. Die Lernbank ist eine redaktionelle Vorschau: wiederkehrende Übungsmuster und ungleich verteilte Fächer; keine vollständige Einzelprüfung, keine verbindliche Lehrplanabdeckung. Orientierungsrahmen: https://zh.lehrplan.ch/. Importierte Fragen ergänzen die feste Bank, können sie nicht mehr durch eine kleine Demodatei ersetzen. XP und Fehlerliste bleiben erhalten. Ein Import ersetzt nur den vorherigen Zusatzbestand. Die ursprüngliche 27er-Datei wird nicht geladen.
 
## Funktionen
**Persönliches Dashboard:** Profilklasse 1–9 explizit auswählen und dauerhaft auf dem Gerät speichern. Schnellstart mit zehn Fragen, Fachtraining, Tages-Challenge und Fehlertraining verwenden ausschliesslich diese Klasse. Eine andere Klasse kann ohne Profiländerung trainiert werden. Der globale Zufallsmodus bleibt frei. Klassenbezogene Antwortstatistik wird ab 0.1.4 erfasst, ältere XP und Fehlerlisten bleiben erhalten. Avatar-Editor mit vier prozeduralen Illustrationsstilen, zufälligen Farb-, Augen- und Detailkombinationen, Vorschau und Speichern; kein Netzwerk, keine persönlichen Bilder, keine generative KI. 
**Alle Fragen · Zufall**: neue direkte Startoption, die ohne Klassen-, Fach- oder Schwierigkeitsfilter aus der gesamten aktiven Fragenbank zieht. 5/10/20/50 oder sämtliche verfügbaren Fragen, zufällig sortiert, ohne Wiederholung innerhalb einer Runde; separate Einstellungen vom gezielten Quiz. Eigenes Kronen-/Buch-/Fragezeichen-Logo in App und Launcher. 
Klasse wählen, ein oder mehrere Fächer, 5/10/20 Fragen, Lernmodus ohne Timer, tägliche Challenge pro Klasse, Fehlertraining, 100 Punkte je richtige Antwort plus 25 Serienbonus ab dritter richtiger Antwort; kein Punktabzug. XP und Fehlerliste lokal. Antworten zufällig sortiert, kein Wiederholen innerhalb einer Runde. Fortschritt wird pro beantworteter Frage gespeichert. Import ergänzt die feste Bank; Gesamtpunkte und Fehlerhistorie bleiben. Keine Cloud. Die App ist eine erste Testversion; Duell, weitere Fragetypen, redaktionelle Prüfung und ausgewogenere Fachverteilung bleiben offen.
 
## Build
JDK 17, Android SDK 35, Gradle 8.10.2. Im Verzeichnis quiz-clash: gradle :app:assembleDebug. Separate CI unter .github/workflows/quiz-clash-android.yml. Debug-APK, nicht Play-Store-signiert.
