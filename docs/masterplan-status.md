# Brain Clash Masterplan – development candidate 0.5.0

Implemented in this candidate: staged configuration, additional maths generators and options, separate stage art for six maths arcade variants, independent local keypads, first-to-ten/perfect/speed rules, reaction false starts, best-of-three/five, local addition knockout and round robin tournaments, target hunting, tap battle, draggable number sorting, timed number bomb, number recall, Stroop-style colored text, daily and weekly goals, XP bonuses, rank, adaptive digit recommendations, SQLite profile migration and recent local history. Existing profile format retained. Existing Flame arena remains for other modes.

Not release-ready: tower/race/rocket/treasure/maze still share the maths scoring engine and lack unique physics or puzzle layouts; tournament uses fixed addition and shared difficulty, no cross-device play, 12 procedural vector characters and six procedural arenas are present, but not individual raster sprite sheets or new audio assets; SQLite profile migration, backup and capped normalized history are implemented but require Android migration tests; no fully localized new strings, no device profiling or production signing verification. CI and physical device tests required before merge/release.
