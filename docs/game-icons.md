# Brain Clash arcade game icons

The four approved 3×3 artwork sheets were cropped without captions, square-padded and encoded as individual 256×256 WebP assets. Every Challenge enum value resolves to a bundled image by name. There are 36 distinct source motifs. Eight related entries share motifs: mathClassic/arithmeticMix, bigTable/timesTable, logic/logicEscape, memory/pairs, focus/targetHunt, words/wordSprint, odd/shapeClash, targetNumber/estimate. No runtime download. A Flutter test checks all 44 assets.
