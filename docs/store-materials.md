# Store assets and release checklist

Listing drafts are in fastlane/metadata/android. `scripts/store_assets.py` builds a 512px launcher icon and a 1024x500 feature image from existing branding and bundled typefaces. The store-assets workflow exports PNG files. It also captures actual home, game setup and duel screens from an Android emulator; no invented gameplay mockups. Before publication review screenshots at native device resolution, capture additional tablet screenshots, and verify all listing claims. No store upload or 1.0 tag before the release gates pass.
