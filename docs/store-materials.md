 # Store assets and release checklist

Store listing drafts are in `fastlane/metadata/android`. The existing brand icon is the source for the 512px store icon. Use real release-candidate screenshots, not mockups: home, math setup, two-player arena, rocket race, collection and progress. Capture at 1080x1920 or native device resolution without personal data; tablet separately. Feature graphic must be 1024x500. Do not imply physical-device verification, Play approval or production signing before evidence exists.
